# Working on this single-project Astro site

This fork began as [Astro Rocket](https://github.com/hansmartensdev/Astro-Rocket). The original theme guidance is preserved in `AGENTS.upstream.md`; keep its advice on accessible components, stable design tokens, and reliable checks wherever compatible.

## Routes and content

- `/` is `src/pages/index.astro`, a single-project product homepage driven by `src/config/project.config.ts`.
- `/docs/` and nested documentation pages are generated by Starlight from `src/content/docs/docs/*.md`.
- `src/content.config.ts` registers Starlight's `docs` collection.
- `src/config/nav.config.ts` contains primary and footer navigation.
- Set the project name, description and accent color in `src/config/project.config.ts`. Build-time code reads the name and color from `src/config/branding.ts`. Edit `src/config/site.config.ts` for other site metadata.
- Upstream blog, projects, services, about, and contact routes were removed deliberately. Do not reintroduce them as a generic theme showcase.

## Automated media

- `pnpm media:capture`: browser screenshots using Playwright, requires a locally running preview server.
- `pnpm media:video`: browser walkthrough recording, then FFmpeg MP4 conversion, requires a preview server.
- `pnpm media:vhs`: terminal PNG/GIF/MP4 produced by Charmbracelet VHS from `scripts/media/tapes/quickstart.tape`. It does **not** screenshot a webpage. VHS/ttyd/FFmpeg or Docker is required.
- `pnpm media:all --docker`: run the browser and terminal captures when the local preview is serving.
- `pnpm media:android`: opt-in Android screenshots and MP4 recordings from an app already open on an emulator or device. Requires Android Platform Tools with `adb` on `PATH`.
- `media-output/` is generated, gitignored output. Do not check rendered media into the repo unless expressly requested.
- `.github/workflows/visual-media.yml` uploads generated assets as Actions artifacts with read-only token permissions.

## Quality gates

Run `pnpm lint`, `pnpm check`, `pnpm build`, and `pnpm check:site`. Always inspect `/` and `/docs/` visually after CSS or routing edits. If you change dependencies, regenerate and commit `pnpm-lock.yaml`; once it exists, CI should use `--frozen-lockfile`.
